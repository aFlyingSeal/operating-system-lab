# Báo cáo đồ án Hệ điều hành

Thư mục này chứa báo cáo của các lab.

## Cấu trúc

- `lab0/` — báo cáo Lab 0 (syscall trace).
  - `lab0-report-v2.md`, `lab0-report-v2.pdf`: bản hiện hành.
  - `24120010_24120035_24120361_Report.pdf`: bản PDF nộp bài Lab 0.
  - `archive/`: draft và các bản v1.
- `lab1/` — báo cáo Lab 1 (quản lý file, quản lý tiến trình, `sysinfo`).
  - `lab1-report.md`: bản Markdown.
  - `latex/`: mã nguồn LaTeX; xem `latex/README.md`.

## Quy ước

- Bản nộp cuối cùng giữ đúng tên `24120010_24120035_24120361_Report.pdf`.
- Không đặt file build LaTeX (`*.aux`, `*.log`, `*.out`, ...) trong thư mục này.
